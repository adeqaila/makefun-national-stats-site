# Nusantara Data

Situs statistik nasional Indonesia: delapan halaman (Beranda, Penduduk, Ekonomi, Kesehatan, Pendidikan, Daerah, Jelajahi Data, Metode & Sumber) yang menyajikan data World Bank 2014–2024 dan data BPS provinsi dalam chart, tabel seri waktu, dan sumber yang tertera di tiap halaman. Halaman Jelajahi Data menyediakan explorer interaktif dengan 25 indikator, slider tahun, dan unduh CSV. Situs ini deterministik dan berjalan tanpa network saat runtime.

## Menjalankan

Buka `app/index.html` langsung di browser, atau serve folder `app/` secara statis:

```sh
python3 -m http.server --directory app 8080
```

Lalu buka http://localhost:8080.
